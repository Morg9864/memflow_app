Memflow functional icon registry
================================

Framework-independent keys map to Lucide icon names. Use the same Lucide name
on Web (lucide-react) and Flutter (lucide_icons_flutter). Functional icons use
a 1.75-equivalent stroke, inherit the current text/accent color, and use 16,
20, or 24 px logical size. User-selected collection emojis are content markers,
not functional interface icons. The 🔥 emoji is also used only for study streaks.

Collection icon fields remain user data and their chosen emoji is rendered in
collection markers. Deck icon fields also remain untouched, but deck markers
always use the Lucide `layers` icon, regardless of the stored legacy value.
